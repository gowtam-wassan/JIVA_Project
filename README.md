# WASSAN Presence – Foot on the Ground Interactive Map

This folder contains all static web assets required to deploy the **WASSAN Presence – Foot on the Ground** interactive map directly to **GitHub Pages**.

## Quick Deployment Steps to GitHub Pages

1. **Upload Files to GitHub**:
   - Create a new repository on GitHub (or use an existing repository).
   - Upload all files inside this `github_pages` directory (`index.html`, `cso_data.json`, `geojson_data.js`, `.nojekyll`, etc.) to your repository's `main` or `gh-pages` branch.

2. **Enable GitHub Pages**:
   - Go to your GitHub repository **Settings** -> **Pages**.
   - Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
   - Select your branch (e.g. `main` or `gh-pages`) and folder `/ (root)`.
   - Click **Save**.

3. **View Your Live Map**:
   - GitHub Pages will publish your site at: `https://<your-username>.github.io/<repository-name>/`
